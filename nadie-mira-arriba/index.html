Cómo jugar

Teclado y mando

A/D o flechas: moverte. Espacio: saltar. W/↑: mirar arriba. Z: agacharte. X: disparar. C: granada. F/V: golpe. Q: cambiar arma. Esc: pausa.

Mando: A salta, B agacha, RT dispara, RB granada, LT mira arriba, X golpe, Y cambia arma, Start confirma / pausa.

Confirma JUGAR con Enter, Espacio, A o Start. El navegador puede necesitar una interacción para activar el sonido.
